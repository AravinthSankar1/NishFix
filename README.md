# Mobile Phone Repair Software Library

A full-stack, production-quality web application built for a mobile phone repair shop owner/admin to upload, organize, manage, publish, and distribute mobile repair software ZIP files, ROMs, and service utilities.

Technicians and public users can browse software by brand/model, search, view installation instructions, and download software ZIP archives directly via secure signed object-storage URLs.

---

## 🛠️ Fixed Technology Stack

* **Frontend**: React (v19), TypeScript, Vite, Tailwind CSS (v4), Lucide Icons, React Router (v7), TanStack Query (v5), React Hook Form, Zod validation.
* **Backend**: Node.js, Express.js, TypeScript, JWT authentication, Bcrypt password hashing.
* **Database**: PostgreSQL with Prisma ORM. Stores metadata, download history logs, and file relationships.
* **Object Storage**: Cloudflare R2 (S3-compatible API). Direct browser-to-storage presigned upload URLs and presigned download URLs. Zero server disk overhead.

---

## 🏗️ Application Architecture

```
                 PUBLIC USER / ADMIN (Browser)
                             |
         +-------------------+-------------------+
         |                                       |
         v                                       v
  React Frontend (Vite)                   Cloudflare R2 Object Storage
   [UI / Search / Cards]                 [Software ZIPs & Images]
         |                                       ^
         | REST API / Auth                       | Direct Presigned
         v                                       | Upload / Download
  Node.js / Express Backend <---------------------+
   [Business Logic / Auth / URL Signer]
         |
         v
  PostgreSQL (Prisma ORM)
   [Metadata & Download Logs]
```

### Key Architectural Safeguards
1. **Presigned R2 Uploads**: Large ZIP files are uploaded directly from the browser to Cloudflare R2 using pre-signed PUT URLs generated by the Node backend. Large files never load into server memory.
2. **Direct R2 Downloads**: When a user clicks **Download**, the backend generates a secure signed GET URL and safely increments the database `downloadCount`. The browser downloads the ZIP file directly from Cloudflare R2.
3. **Free-Tier Storage Quota Awareness**: The Admin dashboard monitors total storage used against a 10 GB free-tier threshold. If storage exceeds the limit, clear administrator-facing errors are shown.
4. **Hyperlinks & External Mirrors**: Admin can provide either a direct ZIP upload to R2, an external download hyperlink (Google Drive, Mega, AndroidFileHost), or both!

## 🚀 Quick Setup & Local Development

### Prerequisites
* **Node.js**: `v20+` or `v24+`
* **PostgreSQL**: Running locally or via Docker
* **npm**: `v10+` or `v11+`

---

### Step 1: Clone & Environment Configuration

Copy environment variable templates:

```bash
# Backend .env configuration
cp backend/.env.example backend/.env

# Root docker configuration
cp .env.example .env
```

Default local `.env` values:
```env
PORT=5000
CLIENT_URL=http://localhost:5173
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/repair_software_db?schema=public
JWT_SECRET=your-jwt-secret-here
ADMIN_EMAIL=your-admin-email@example.com
ADMIN_PASSWORD=your-secure-password-here
```

---

### Step 2: Database Setup & Seed

1. Ensure PostgreSQL is running on port `5432` with database `repair_software_db`.
2. Generate Prisma client & run initial database seed:

```bash
cd backend
npm install
npx prisma generate
npx prisma db push
npm run prisma:seed
```

The seed script creates the default admin user:
* **Admin Email**: `admin@repair.local`
* **Admin Password**: `AdminPass123!`
* Sample software entries for Samsung, Xiaomi, Apple, Oppo, Vivo, MediaTek, and Qualcomm.

---

### Step 3: Start Backend API

```bash
cd backend
npm run dev
```

Backend API runs at: `http://localhost:5000`

---

### Step 4: Start Frontend Client

```bash
cd frontend
npm install
npm run dev
```

Frontend application runs at: `http://localhost:5173`

---

## 🐳 Docker Deployment

To run the complete stack (PostgreSQL + Express Backend + Nginx React Frontend) in Docker containers:

```bash
docker-compose up --build
```

Access points:
* **Frontend Web App**: `http://localhost:80`
* **Backend API**: `http://localhost:5000`
* **PostgreSQL DB**: `localhost:5432`

## 🔑 Admin Flow & Credentials

1. Navigate to `/login` or click **Admin Login** in the top navigation.
2. Login using `admin@repair.local` / `AdminPass123!`.
3. Access the **Admin Dashboard** (`/admin`):
   * View live Cloudflare R2 storage gauge and usage breakdown.
   * Add new repair software packages (Enter Brand, Model, Version, Software Name, thumbnail image, ZIP file upload, and optional mirror hyperlink).
   * Publish, Unpublish (Draft), Archive, or Delete software packages.

## 📡 Key REST API Reference

### Public API
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/software` | List published software (supports search, brand filter, pagination) |
| `GET` | `/api/software/brands` | Get list of brands with item counts |
| `GET` | `/api/software/:id` | Get details for single published software |
| `POST` | `/api/software/:id/download` | Generate secure presigned R2 download URL & increment counter |

### Admin API (Protected by JWT)
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/auth/login` | Admin login & issue JWT token |
| `GET` | `/api/admin/dashboard` | Get KPI stats & R2 storage usage metrics |
| `GET` | `/api/admin/software` | List all software entries (including Drafts and Archived) |
| `POST` | `/api/admin/software` | Create new software metadata entry |
| `PUT` | `/api/admin/software/:id` | Edit software metadata entry |
| `DELETE` | `/api/admin/software/:id` | Delete software record and remove associated R2 storage objects |
| `POST` | `/api/admin/software/:id/publish` | Set status to `PUBLISHED` |
| `POST` | `/api/uploads/presigned-url` | Generate presigned PUT URL for direct browser upload to R2 |
